# @polaris/shared-types

Canonical OpenAPI contract and generated TypeScript types for POLARIS clients (web, mobile, desktop).

## Layout

- `openapi/polaris-v1.yaml` — source of truth for `/api/v1`
- `src/generated/api.ts` — generated by `openapi-typescript` (do not edit by hand)
- `dist/` — published package output

## TypeScript consumers

```bash
npm install @polaris/shared-types
# or link locally during development:
npm install file:../shared-types
```

```ts
import { apiPath, type paths } from "@polaris/shared-types";

type Health = paths["/health"]["get"]["responses"]["200"]["content"]["application/json"];
```

## Python (backend-api)

Keep Pydantic models aligned with the same OpenAPI document:

```bash
pip install datamodel-code-generator
datamodel-codegen --input openapi/polaris-v1.yaml --output ../backend-api/app/schemas/generated.py
```

Regenerate when the spec changes. CI in both repos should fail on contract drift.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run codegen` | Regenerate `src/generated/api.ts` |
| `npm run build` | Codegen + compile to `dist/` |
| `npm run lint:openapi` | Spectral lint on the spec |

## Versioning

Package semver tracks API breaking changes. Pin the same version in `web-frontend`, `mobile-development`, and backend release tags.
